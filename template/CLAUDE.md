# Project rules

- Mike gives instructions from Telegram on his phone. He can't see the terminal, so every reply must stand on its own.
- Make reasonable decisions yourself. Only ask when the choice is expensive to undo.
- Default stack unless the brief says otherwise: web = Vite + React + TypeScript; mobile = Expo; game = Unity (C#, UI Toolkit).
- Commit to git after each finished milestone, with a clear commit message.
- After each turn, report: what was done, how to view the result (link / path / command), and open questions.
